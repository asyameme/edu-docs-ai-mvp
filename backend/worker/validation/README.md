# Этапы проверки

`rules.yaml` разделяет два запуска одного rule engine:

- `document_reconciliation` проверяет результаты парсинга до построения графа и
  помогает пользователю разрешить расхождения между документами.
- `graph_validation` запускает применимые правила для актуального состояния
  после создания графа и после каждой правки через чат. На вход передаются
  проекции именно проверяемой версии графа; исходные JSON после правок могут
  быть устаревшими.

Каждое правило явно перечисляет стадии в `phases`. Текущие проверки применимы к
обоим этапам. Если правило должно работать только на одном этапе, укажите только
его в `phases`. Для проверки графа после правок вызывающая сторона должна
построить проекции актуальной версии и вызвать `run_validation(...,
phase="graph_validation")`.

Поле `status` управляет запуском независимо от фазы: `ready` и
`ready_with_semantic_fallback` запускаются, а `draft` пропускаются и не входят
в отчёт. Неизвестный или отсутствующий статус отклоняется при проверке
конфигурации. Статус `ready_with_semantic_fallback` означает, что семантическая
проверка запускается, а её неопределённые случаи или недоступность модели
передаются на ручную проверку согласно обработчику правила.

Для R-04 проектом утверждено `inputs.hours_per_credit_unit: 36`: валидатор
сопоставляет `hours_total` с `credit_units × 36` в записях дисциплин и
семестровой нагрузки РПД, РПП и учебного плана. Это рабочий параметр проекта;
он сам по себе не устанавливает применимость конкретной редакции ФГОС или ОС
СПбГУ. Поля часов и ЗЕТ в текущем контракте целочисленные, поэтому применяется
точное равенство без округления.

Структурные ограничения самого `SnapshotV2` (уникальность ID, существование
концов связей и источников, корректность provenance) остаются в Pydantic-модели
и проверяются при валидации снимка. Они не дублируются как правила YAML.

В этой ветке нет адаптера «граф → проекции документов» и вызова rule engine из
API после каждой правки. Этапы и входной контракт валидатора уже разделены;
подключение повторного запуска требует передачи текущей версии графа из
бекенда.
