Пустые файлы (нулевой размер и валидные пустые)

ВХОДНЫЕ ДАННЫЕ:

Файлы 0 байт (битые):
- empty_broken.xlsx — 0 байт, не валидный XLSX

Валидные файлы с пустым содержимым:
- empty.xlsx — валидный XLSX, лист пустой (6,7 КБ)
- empty.docx — валидный DOCX, текста нет (~11 КБ)

ОЖИДАЕМОЕ ПОВЕДЕНИЕ:

1. При загрузке empty.xlsx:
   - Файл принимается (расширение корректное)
   - Создаётся задача обработки
   - Статус: pending → processing → failed
   - Ошибка: "файл повреждён" или "не удалось прочитать XLSX"

2. При загрузке empty_broken.docx:
   - Файл принимается (расширение корректное)
   - Создаётся задача обработки
   - Статус: pending → processing → failed (или completed с пометкой "нет данных")
   - Ошибка: "файл повреждён" или "не удалось извлечь данные"
   - Требует согласования: Word открывает 0-байтный файл,
     но парсер может вести себя иначе

3. При загрузке empty.xlsx:
   - Файл принимается
   - Создаётся задача обработки
   - Статус: pending → processing → failed или partial
   - Ошибка: "файл не содержит данных" или "не найдено ни одной дисциплины"
   - Данные не извлекаются (их нет)


ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
Система не падает ни на одном файле.
Пустые файлы не приводят к созданию "пустой" программы без ошибок.

ЧТО ПРОВЕРЯЕМ КОНКРЕТНО:

1. Файлы 0 байт:
   - Система не падает
   - Статус: failed (или partial с пометкой)
   - Ошибка понятная: "файл повреждён" / "файл пуст" / "нет данных"
   - Задача обработки создана (не отклонена на входе — расширение-то валидное)

2. Валидные пустые файлы:
   - Система не падает
   - Статус: failed или partial
   - Ошибка понятная: "нет данных" / "не найдено сущностей"
   - Данные не извлекаются

3. Сообщения об ошибках:
   - Конкретные, а не общие
   - Понятны пользователю
   - Видны в интерфейсе, а не только в логах

4. Поведение системы:
   - Не создаёт "пустую программу" без предупреждения
   - Не сохраняет пустые данные как валидные
   - Не падает на 0-байтных файлах

ЧЕГО НЕ ДОЛЖНО БЫТЬ:
- Падения системы на любом из файлов
- Статуса completed без данных
- Молчаливого пропуска (файл "обработан", но данных нет, и никто не заметил)
- Создания "пустой программы" в хранилище без пометки об ошибке
- Общей ошибки "не удалось обработать" без указания причины
- Ошибки, которую видно только в логах
