Фиксация ошибок разбора (нераспознанные данные)

ВХОДНЫЕ ДАННЫЕ:
- bad_values.xlsx    — УП с нечисловыми значениями:
                       * Математический анализ I, колонка «Семестр»: "҉҉"
                       * Введение в системы баз данных, колонка
                         «В т.ч. с использованием учебно-методич. материалов»: "ӘӘӘ"
                       * Учебная практика, колонка «Семестр»: "ДВА"
- bad_table.docx     — РПД с пустыми ячейками в таблице 2.1.1:
                       * Лекции — пусто (было 30)
                       * Промежуточная аттестация (контактная) — пусто (было 4)
                       * Промежуточная аттестация (итого) — пусто (было 4)
                       * Трудоёмкость (итого) — пусто (было 4)

ОЖИДАЕМОЕ ПОВЕДЕНИЕ:

1. При загрузке bad_values.xlsx:
   - Файл принимается
   - Обработка запускается
   - Система находит нечисловые значения в колонках
   - Статус: partial (или completed с предупреждениями)
   - Список нераспознанных данных:
     * "Строка 1 (Математический анализ I), колонка 'Семестр':
        значение '҉҉' не является числом"
     * "Строка 3 (Введение в системы баз данных), колонка
        'В т.ч. с использованием учебно-методич. материалов':
        значение 'ӘӘӘ' не является числом"
     * "Строка 4 (Учебная практика), колонка 'Семестр':
        значение 'ДВА' не является числом"
   - Остальные дисциплины извлекаются корректно

2. При загрузке bad_table.docx:
   - Файл принимается
   - Обработка запускается
   - Система извлекает данные, но находит пустые ячейки
   - Статус: partial (или completed с предупреждениями)
   - Список нераспознанных данных:
     * "Таблица 2.1.1, строка 'Лекции': значение отсутствует"
     * "Таблица 2.1.1, строка 'Промежуточная аттестация'
        (контактная работа): значение отсутствует"
     * "Таблица 2.1.1, строка 'Промежуточная аттестация' (итого):
        значение отсутствует"
     * "Таблица 2.1.1, строка 'Трудоёмкость' (итого): значение отсутствует"
   - Пользователь видит, ЧТО именно не распознано

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
Система НЕ молчит. Она показывает список нераспознанных данных
с указанием строки, колонки и причины.

ЧТО ПРОВЕРЯЕМ КОНКРЕТНО:

1. Список ошибок разбора:
   - Формируется для каждого файла с проблемами
   - Содержит: файл, строку, колонку, причину
   - Не общий ("ошибка разбора"), а конкретный

2. Формат ошибки:
   - "Строка X, колонка Y: <причина>"
   - Понятно пользователю без технических деталей

3. Полнота:
   - В bad_values.xlsx найдены ВСЕ три нечисловых значения
   - В bad_table.docx найдены ВСЕ четыре пустые ячейки
   - Не только первая ошибка

4. Поведение системы:
   - Не падает на битых данных
   - Не молчит (не пропускает пустые ячейки как норму)
   - Извлекает то, что можно извлечь
   - Помечает то, что не удалось извлечь

ЧЕГО НЕ ДОЛЖНО БЫТЬ:
- Молчаливого пропуска битых данных
- Общей ошибки "не удалось обработать" без деталей
- Статуса completed, если часть данных не распознана
- Потери уже распознанных данных из-за одной битой ячейки
- Падения системы
- Ошибки, которую видно только в логах
- Нахождения только первой ошибки (нашёл 1 из 4 — баг)
