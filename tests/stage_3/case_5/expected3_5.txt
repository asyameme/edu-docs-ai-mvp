Статусы обработки (успех и ошибка)

ВХОДНЫЕ ДАННЫЕ:
- valid.xlsx      — копия UP_short.xlsx (успешная обработка)
- corrupted.docx  — копия broken.docx (провальная обработка)

ОЖИДАЕМОЕ ПОВЕДЕНИЕ:

СЦЕНАРИЙ 1 (успешная обработка):

1. Загрузка valid.xlsx:
   - Файл принят
   - Создана задача обработки
   - Статус: pending

2. Обработка началась:
   - Статус: processing
   - Прогресс: 0% → ... → 100%
   - Прогресс обновляется, не стоит на месте

3. Обработка завершена:
   - Статус: completed
   - Прогресс: 100%
   - Данные доступны для просмотра

СЦЕНАРИЙ 2 (провальная обработка):

1. Загрузка corrupted.docx:
   - Файл принят (расширение валидное)
   - Создана задача обработки
   - Статус: pending

2. Обработка началась:
   - Статус: processing
   - Прогресс: 0% → ... → N% (останавливается на моменте ошибки)

3. Обработка провалилась:
   - Статус: failed
   - Прогресс: N% (не 100%)
   - Ошибка: "файл повреждён" или "не удалось прочитать DOCX"

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
Статусы меняются последовательно. Прогресс обновляется.
Ошибки видны пользователю.

ЧТО ПРОВЕРЯЕМ КОНКРЕТНО:

1. Последовательность статусов:
   - pending → processing → completed (для valid.xlsx)
   - pending → processing → failed (для corrupted.docx)
   - Нет перескоков (pending → completed напрямую)
   - Нет застревания на processing

2. Прогресс:
   - Обновляется во время processing
   - Достигает 100% при completed
   - Останавливается на N% при failed
   - Не откатывается назад (100% → 50% — баг)

3. Сообщения об ошибках:
   - При failed видна причина: "файл повреждён" / "не удалось прочитать"
   - Не общие ("ошибка")
   - Понятны пользователю

4. Поведение системы:
   - Не падает при ошибке обработки
   - Не "зависает" на processing навсегда
   - Не показывает completed при ошибке

ЧЕГО НЕ ДОЛЖНО БЫТЬ:
- Перескока статусов (pending → completed)
- Застревания на processing
- Прогресса, который не обновляется
- Прогресса, который откатывается назад
- Статуса completed при ошибке
- Статуса failed без причины
- Ошибки, которую видно только в логах
- Падения системы
