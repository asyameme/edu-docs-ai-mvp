Поддерживаемые форматы (валидные и невалидные файлы)

ВХОДНЫЕ ДАННЫЕ:

Валидные (должны приниматься):
- valid.xlsx — копия UP_short.xlsx (учебный план)
- valid.docx — копия РПД_языки программирования.docx (рабочая программа)


Невалидные (должны отклоняться):
- invalid.txt — текстовый файл
- invalid.jpg — картинка (JPEG)
- invalid.bmp — картинка (BMP)
- invalid.zip — архив

ОЖИДАЕМОЕ ПОВЕДЕНИЕ:

1. При загрузке valid.xlsx:
   - Файл принимается
   - Создаётся задача обработки
   - Статус: pending → processing → completed
   - Данные извлекаются

2. При загрузке valid.docx:
   - Файл принимается
   - Создаётся задача обработки
   - Статус: pending → processing → completed
   - Данные извлекаются

3. При загрузке invalid.txt:
   - Файл отклоняется
   - Ошибка: "формат .txt не поддерживается"
   - Задача обработки не создаётся
   - Статус: rejected (или failed)

4. При загрузке invalid.jpg:
   - Файл отклоняется
   - Ошибка: "формат .jpg не поддерживается"
   - Задача обработки не создаётся

5. При загрузке invalid.bmp:
   - Файл отклоняется
   - Ошибка: "формат .bmp не поддерживается"
   - Задача обработки не создаётся

6. При загрузке invalid.zip:
   - Файл отклоняется
   - Ошибка: "формат .zip не поддерживается"
   - Задача обработки не создаётся

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
Валидные форматы принимаются, невалидные отклоняются с понятной ошибкой.
Система не падает ни на одном файле.

ЧТО ПРОВЕРЯЕМ КОНКРЕТНО:

1. Валидные форматы:
   - XLSX принимается
   - DOCX принимается
   - Для каждого создаётся задача обработки

2. Невалидные форматы:
   - TXT отклоняется
   - JPG отклоняется
   - BMP отклоняется
   - ZIP отклоняется

3. Сообщения об ошибках:
   - Указывают, какой именно формат не поддерживается
   - Не общие ("ошибка"), а конкретные ("формат .txt не поддерживается")
   - Понятны пользователю

4. Поведение системы:
   - Не падает при загрузке невалидного файла
   - Не создаёт задачу обработки для отклонённых файлов
   - Не сохраняет отклонённые файлы в хранилище

ЧЕГО НЕ ДОЛЖНО БЫТЬ:
- Падения системы на любом из файлов
- Молчаливого принятия TXT/JPG/BMP/ZIP
- Создания задачи обработки для отклонённых файлов
- Общей ошибки без указания причины
- Ошибки, которую видно только в логах, но не в интерфейсе
- Принятия файла без расширения как "валидного" по умолчанию
