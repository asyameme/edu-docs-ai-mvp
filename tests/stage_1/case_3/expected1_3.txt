Кейс: внутренняя сумма часов и з.е. в РПП не сходится
Практика: Учебная практика (проектно-технологическая), 064682

ВХОДНЫЕ ДАННЫЕ:
- С2-5_ТОП__Учебная практика (проектно-технологическая).docx
  → РПП с испорченным разделом 2.1 «Организация практики»
  (без УП — проверяется только внутренняя согласованность РПП)

ОРИГИНАЛ (для сравнения):
Общая трудоёмкость: 18 з.е. (648 часов)
Распределение по семестрам:
  Семестр 2: 3 з.е. (108 часов)
  Семестр 3: 3 з.е. (108 часов)
  Семестр 4: 6 з.е. (216 часов)
  Семестр 5: 6 з.е. (216 часов)
Сумма по семестрам: 18 з.е., 648 часов — сходится с общей.

ЧТО ИСПОРЧЕНО:
В РПП, раздел 2.1:
- Общая трудоёмкость в часах: 648 → 612
- Семестр 4: 6 з.е. → 4 з.е. (часы 216 не тронуты)

=== Конфликт 1: внутренний — сумма часов по семестрам vs общая ===
Сумма часов по семестрам: 108 + 108 + 216 + 216 = 648
Заявленная общая трудоёмкость: 612 часов
Расхождение: 648 ≠ 612
Ожидание: система показывает конфликт
"Сумма часов по семестрам (648) не сходится с общей трудоёмкостью (612)".

=== Конфликт 2: внутренний — сумма з.е. по семестрам vs общая ===
Сумма з.е. по семестрам: 3 + 3 + 4 + 6 = 16
Заявленная общая трудоёмкость: 18 з.е.
Расхождение: 16 ≠ 18
Ожидание: система показывает конфликт
"Сумма з.е. по семестрам (16) не сходится с общей трудоёмкостью (18)".

=== Конфликт 3: внутренний — семестр 4, з.е. vs часы ===
В семестре 4: заявлено 4 з.е. (216 часов)
4 з.е. × 36 = 144 часа, а не 216
Расхождение: 144 ≠ 216 (4 з.е. не соответствуют 216 часам)
Ожидание: система показывает конфликт
"В семестре 4: 4 з.е. не соответствуют 216 часам (должно быть 6 з.е.)".

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
Система находит ВСЕ ТРИ конфликта.
Ни один не потерян, ни один не «схлопнут» в другой.

ЧЕГО НЕ ДОЛЖНО БЫТЬ:
- Пропуска конфликта (нашёл 1 из 3 — баг)
- «Схлопывания» конфликтов 1, 2, 3 в один
- Потери одного из значений в конфликте
- Дублей конфликтов
- Конфликта без ссылки на сущности
- Конфликта без типа
- Конфликта без статуса
- Молчаливого пропуска (система «не заметила» расхождение)
