Версионирование после правки (v1 → v2 → возврат к v1)

ВХОДНЫЕ ДАННЫЕ:
- UP_short.xlsx                              — учебный план
- С1_001856_Математический анализ I.docx     — РПД с конфликтом (из кейса 2.5)

СЦЕНАРИЙ:
1. Загрузка UP_short.xlsx → создаётся версия 1 (только УП).
2. Загрузка С1_001856_Математический анализ I.docx → создаётся версия 2
   (УП + РПД), в ней появляются конфликты.
3. Возврат к версии 1 → состояние как в шаге 1.

ОЖИДАЕМОЕ ПОВЕДЕНИЕ:

Шаг 1 (создание v1):
1. Загружается UP_short.xlsx.
2. Создаётся версия 1 программы.
3. В v1: только УП, конфликтов нет.

Шаг 2 (создание v2):
1. Загружается РПД по матану.
2. Создаётся версия 2 на основе v1 + РПД.
3. В v2 появляются конфликты между УП и РПД:
   - внутреннее несоответствие часов в РПД
   - расхождение з.е. шапки РПД и таблицы
   - расхождение з.е. УП и РПД
4. Версия 1 остаётся неизменной — в ней по-прежнему нет конфликтов.
5. Версия 2 сохранена.

Шаг 3 (возврат к v1):
1. Пользователь читает версию 1.
2. В v1: только УП, конфликтов нет.
3. Версия 2 при этом не удаляется — она остаётся доступной.
4. Переключение v2 → v1 не влияет на v2.

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
Версии изолированы. Возврат к v1 не ломает v2.
Конфликты есть только в v2.

ЧТО ПРОВЕРЯЕМ КОНКРЕТНО:

1. Создание v1:
   - v1 создана
   - В v1: данные только из УП
   - Конфликтов нет

2. Создание v2:
   - v2 создана
   - В v2: данные УП + РПД
   - В v2: конфликты (внутренние и внешние)
   - v1 не изменилась

3. Чтение v1 после создания v2:
   - Возвращает данные v1
   - Конфликтов нет
   - Не подтягивает данные из v2

4. Чтение v2 после создания:
   - Возвращает данные v2
   - Конфликты на месте
   - Данные из v1 тоже видны (v2 = v1 + РПД)

5. Переключение v2 → v1 → v2:
   - v1 остаётся как была
   - v2 остаётся как была
   - Данные не смешиваются

ЧЕГО НЕ ДОЛЖНО БЫТЬ:
- После создания v2 в v1 появились конфликты
- После возврата к v1 конфликты остались (они относятся только к v2)
- v1 перезаписана данными из v2
- v2 удалена после возврата к v1
- Данные из v2 «протекли» в v1
- Конфликты «прилипли» к программе, а не к версии
