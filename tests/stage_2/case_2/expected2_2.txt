Версионирование матрицы компетенций (v1 vs v2)

ВХОДНЫЕ ДАННЫЕ:
- Матрица_компетенций_old.xlsx — матрица покрытия, версия 1
- Матрица_компетенций.xlsx     — матрица покрытия, версия 2

СЦЕНАРИЙ:
1. Загрузка Матрица_компетенций_old.xlsx → создаётся версия 1.
2. Загрузка Матрица_компетенций.xlsx → создаётся версия 2.
3. Система сравнивает версии и формирует список изменений.
4. Версия 1 остаётся неизменной после создания версии 2.

ОЖИДАЕМЫЙ СПИСОК ИЗМЕНЕНИЙ:

1. Компетенция ПКП-24-РГ-5:
   - Тип изменения: добавлена колонка
   - Есть в v2, отсутствует в v1
   - Это новая компетенция в матрице

2. Связь "Алгебра и геометрия ↔ УК-4":
   - Тип изменения: изменено значение
   - Было: 0 (не формируется)
   - Стало: 1 (формируется)

3. Связь "История России ↔ УК-1":
   - Тип изменения: изменено значение
   - Было: 0
   - Стало: 1

4. Связь "Русский язык как иностранный ↔ ОПК-4":
   - Тип изменения: изменено значение
   - Было: 0
   - Стало: 1

5. Связь "История России (2 сем) ↔ УКБ-1":
   - Тип изменения: изменено значение
   - Было: 0
   - Стало: 1

6. Итоговые строки:
   - В v1 и v2 используются формулы СУММ и СУММЕСЛИ
   - Данные в ячейках изменились, но формулы в файле остались
   - Тип: потенциальное несоответствие
   - Система должна либо пересчитать формулы, либо предупредить о расхождении

ОЖИДАЕМЫЕ КОНФЛИКТЫ / ПРЕДУПРЕЖДЕНИЯ:
- "Компетенция ПКП-24-РГ-5 добавлена в версии 2"
- "Связь 'Алгебра и геометрия ↔ УК-4' изменилась: 0 → 1"
- "Связь 'История России ↔ УК-1' изменилась: 0 → 1"
- "Связь 'Русский язык как иностранный ↔ ОПК-4' изменилась: 0 → 1"
- "Связь 'История России (2 сем) ↔ УКБ-1' изменилась: 0 → 1"
- "Итоговые значения формул не соответствуют данным (если итого НЕ считается по формулам)" 
- "В матрице 4 изменения связей + 1 добавленная компетенция"

ЧТО ПРОВЕРЯЕМ КОНКРЕТНО:

1. Создание версий:
   - v1 создана из Матрица_компетенций_old.xlsx
   - v2 создана из Матрица_компетенций.xlsx
   - v1 остаётся неизменной

2. Изоляция версий:
   - При чтении v1 — старые данные
   - При чтении v2 — новые данные
   - Данные не смешиваются

3. Полнота изменений:
   - Найдены ВСЕ 5 изменений (4 ячейки + 1 колонка)
   - Не только первое
   - Не «схлопнуто» в одно сообщение

4. Типы изменений:
   - Добавление компетенции в матрицу (ПКП-24-РГ-5)
   - Изменение значения связи (4 штуки, все 0 → 1)
   - Несоответствие итоговых результатов данным

5. Формулы:
   - Если система пересчитывает формулы — итоги новые
   - Если читает raw — итоги старые
   - Требует согласования с командой

ЧЕГО НЕ ДОЛЖНО БЫТЬ:
- Смешивания данных v1 и v2
- Потери версии 1 после создания версии 2
- Пропуска одного из 5 изменений
- Остановки после первого найденного изменения
- Ложных изменений в ячейках, которые не менялись
- Игнорирования добавленной компетенции ПКП-24-РГ-5
- Игнорирование возможного несоответствия итоговых результатов данным
