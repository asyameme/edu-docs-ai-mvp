Сохранение и чтение сущностей (дисциплины, компетенции, индикаторы, связи)

ВХОДНЫЕ ДАННЫЕ:
- РПД_БД.docx                    — рабочая программа дисциплины
                                    «Введение в системы баз данных»
- Общая_характеристика_corr.docx — общая характеристика программы

ОЖИДАЕМОЕ ПОВЕДЕНИЕ:
1. При загрузке РПД_БД.docx система извлекает:
   - сущность «Дисциплина»: [056789] Введение в системы баз данных, 4 з.е.
   - сущность «Компетенции дисциплины»: ОПК-4, ОПК-5, ПКП-ППК-Р4,
     ПКП-ППК-Р5, ПКП-ППК-ДА6
   - сущности «Индикаторы»: ОПК-4.1, ОПК-4.2, ОПК-4.3, ОПК-5.1, ОПК-5.2,
     ПКП-ППК-Р4.1, ПКП-ППК-Р4.2, ПКП-ППК-Р4.3, ПКП-ППК-Р5.1, ПКП-ППК-Р5.2,
     ПКП-ППК-ДА6.1, ПКП-ППК-ДА6.2
   - связи «Дисциплина ↔ Компетенция»
2. При загрузке Общая_характеристика_corr.docx система извлекает:
   - сущности «Компетенция»: полный список из ОХ
   - индикаторы каждой компетенции (если указаны)
3. Все сущности сохраняются в хранилище отдельно друг от друга.
4. При чтении каждой сущности по ID возвращается её содержимое.
5. Связи между сущностями сохраняются и читаются корректно.

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
Каждая сущность и каждая связь сохранены и читаются идентично исходным данным.

ЧТО ПРОВЕРЯЕМ КОНКРЕТНО:

1. Сущность «Дисциплина» (Введение в системы баз данных):
   - Код: [056789]
   - Название: Введение в системы баз данных
   - Трудоёмкость: 4 з.е.
   - Сохраняется как отдельная запись с уникальным ID
   - Читается по ID без потерь

2. Сущности «Компетенция»:
   - ОПК-4, ОПК-5, ПКП-ППК-Р4, ПКП-ППК-Р5, ПКП-ППК-ДА6
   - Каждая сохраняется как отдельная запись с уникальным ID
   - У каждой компетенции: код, название, категория, индикаторы
   - Чтение каждой компетенции по ID возвращает её индикаторы

3. Сущности «Индикатор»:
   - Все 12 индикаторов сохранены
   - Каждый привязан к своей компетенции
   - ОПК-4.1, ОПК-4.2, ОПК-4.3 → ОПК-4
   - ОПК-5.1, ОПК-5.2 → ОПК-5
   - ПКП-ППК-Р4.1, ПКП-ППК-Р4.2, ПКП-ППК-Р4.3 → ПКП-ППК-Р4
   - ПКП-ППК-Р5.1, ПКП-ППК-Р5.2 → ПКП-ППК-Р5
   - ПКП-ППК-ДА6.1, ПКП-ППК-ДА6.2 → ПКП-ППК-ДА6

4. Связи «Дисциплина ↔ Компетенция»:
   - Введение в системы баз данных ↔ ОПК-4
   - Введение в системы баз данных ↔ ОПК-5
   - Введение в системы баз данных ↔ ПКП-ППК-Р4
   - Введение в системы баз данных ↔ ПКП-ППК-Р5
   - Введение в системы баз данных ↔ ПКП-ППК-ДА6
   - Каждая связь имеет свой ID
   - Связь ссылается на существующие сущности
   - Нет битых ссылок

5. Целостность:
   - Нет осиротевших сущностей
   - Нет дублей
   - Нет потерянных связей

ЧЕГО НЕ ДОЛЖНО БЫТЬ:
- Потери индикаторов при сохранении компетенции
- Потери связей между дисциплиной и компетенциями
- Битых ссылок (связь ведёт на несуществующую сущность)
- Осиротевших сущностей
- Дублей (одна и та же компетенция сохранена дважды)
- Потери категории компетенции (ОПК, ПКП)
- Потери формулировки индикатора
- Искажения кода дисциплины ([056789] → [56789])
- Искажения кодов компетенций (ПКП-ППК-Р4 → ПКП-ППК-P4,
  где P — латинская вместо русской)
