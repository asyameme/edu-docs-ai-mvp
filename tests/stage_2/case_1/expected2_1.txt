Версионирование учебного плана (v1 vs v2)

ВХОДНЫЕ ДАННЫЕ:
- UP_short_old.xlsx — учебный план, версия 1
- UP_short.xlsx     — учебный план, версия 2

СЦЕНАРИЙ:
1. Загрузка UP_short_old.xlsx → создаётся версия 1 программы.
2. Загрузка UP_short.xlsx → создаётся версия 2 программы.
3. Система сравнивает версии и формирует список изменений.
4. Версия 1 остаётся неизменной после создания версии 2.

ОЖИДАЕМЫЙ СПИСОК ИЗМЕНЕНИЙ:

1. Дисциплина "Языки программирования":
   - Тип изменения: добавлена
   - Есть в v2, отсутствует в v1

2. Дисциплина "Введение в системы баз данных":
   - Тип изменения: добавлена
   - Есть в v2, отсутствует в v1

3. Дисциплина "Основы Python":
   - Тип изменения: удалена
   - Есть в v1, отсутствует в v2

4. Дисциплина "Математический анализ I":
   - Тип изменения: изменены часы и компетенции
   - Практические занятия: 24 → 60
   - Компетенции: убрана "ПКА-1" (было "УК-1, УНК-3, ОПК-1, ПКА-1",
     стало "УК-1, УНК-3, ОПК-1")

5. Дисциплина "Учебная практика (проектно-технологическая)":
   - Тип изменения: изменена форма контроля
   - Вид контроля: "зачёт" → "экзамен"

6. Пустые строки в v1:
   - В UP_short_old.xlsx между строками таблицы есть пустые строки
   - Тип: предупреждение
   - Система должна либо игнорировать их, либо выдать предупреждение
     "в таблице обнаружены пустые строки"

ОЖИДАЕМЫЕ КОНФЛИКТЫ / ПРЕДУПРЕЖДЕНИЯ:
- "Дисциплина 'Языки программирования' добавлена в версии 2"
- "Дисциплина 'Введение в системы баз данных' добавлена в версии 2"
- "Дисциплина 'Основы Python' удалена в версии 2"
- "Часы дисциплины 'Математический анализ I' изменились: практические 24 → 60"
- "Компетенции дисциплины 'Математический анализ I' изменились"
- "Форма контроля дисциплины 'Учебная практика' изменилась: зачёт → экзамен"
- "В таблице обнаружены пустые строки" (если система это отслеживает)

ЧТО ПРОВЕРЯЕМ КОНКРЕТНО:

1. Создание версий:
   - v1 создана из UP_short_old.xlsx
   - v2 создана из UP_short.xlsx
   - v1 остаётся неизменной после создания v2

2. Изоляция версий:
   - При чтении v1 — данные из UP_short_old.xlsx
   - При чтении v2 — данные из UP_short.xlsx
   - Данные не смешиваются

3. Полнота изменений:
   - Найдены ВСЕ 5 типов изменений (добавления, удаления, изменения)
   - Не только первое изменение
   - Не «схлопнуто» в одно сообщение

4. Типы изменений:
   - Добавление дисциплины (Языки программирования, БД)
   - Удаление дисциплины (Основы Python)
   - Изменение часов (Матан: 24 → 60)
   - Изменение компетенций (Матан: убран ПКА-1)
   - Изменение формы контроля (Практика: зачёт → экзамен)

ЧЕГО НЕ ДОЛЖНО БЫТЬ:
- Смешивания данных v1 и v2
- Потери версии 1 после создания версии 2
- Ложных изменений у дисциплин, которые не менялись
- Пропуска одного из изменений (нашёл 3 из 5 — баг)
- Остановки после первого найденного изменения
- Падения системы на пустых строках в v1
